==> I git clone my project in a different machine. But I originally .gitignored the .env file. 
Now I don't have access to the .env variables from the other machine. 
What is the best practice to share the .env file via git repository for development environment?
Sol: Include a .sample.env file in your repository. This file should define the variable names but only include dummy data or blanks for the actual values1.
Users cloning or forking the repository can then copy .sample.env to .env and assign real values to the variables.
