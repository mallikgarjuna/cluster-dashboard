# ClusterDashboard.com
- This is an internal grant-tracker application, a dashboard for streamlining grant application data from researchers within a cluster (consisting of 3 departments) at UMCG.
- It is currently being used in the cluster Biomedical Sciences and Technology (BST) at UMCG
- Whole app is behind the user authentication.
- One would need an approval from the managing director of the cluster to access the app.


## Tech stack used
This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

- Javascript/ Typescript
- Tailwind CSS
- NextUI -> Shadcn
- React.js
- Next.js
- Prima ORM
- Supabase for cloud based Postgres db server
- Docker compose for setting up local Postgres db server
- Vercel for deployment (with their generous free-tier)
- Git and Github
